# Canonical five-fold checkpoints

The five `best_model_fold_*.pth` files are from run
`20260908_225152_bafsynpred`. Each checkpoint is evaluated only on the
corresponding validation fold defined in
`data/kfold_splits_processed/5_fold_splits.npy`.

The bundled metadata records the exact configuration and reported metrics.
Checkpoint and source hashes are also fixed in `release_manifest.json`.
