# Data included for reproducibility

- `10183_drug_feature_0_30.csv`: 10,183 drug-pair/cell-line observations.
- `10183_cell_features_977.npy`: 37 cell lines with 977 expression features.
- `kfold_splits_processed/5_fold_splits.npy`: fixed five-fold record-level split.

Expected SHA-256 values are recorded in the repository-level
`release_manifest.json`. Generated molecular graph caches are written below
`data/cache/` and are intentionally not versioned.
